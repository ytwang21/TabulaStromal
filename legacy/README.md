# Historical analysis sources

These notebooks and scripts provide the original annotation, integration and exploratory context. Notebook execution outputs and personal server paths have been removed. Commands may require original H5AD files, local language-model checkpoints, historical downstream objects and additional packages. They are not part of the supported one-command benchmark or the CI execution claim.

For new analyses, start with `workflows/` and the data contract. Marker labels and illustrative historical figures do not override the audited model/evaluation scope in `docs/results.md`.
