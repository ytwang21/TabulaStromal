# Result evidence ledger

[evidence_registry.csv](evidence_registry.csv) records exact source files, row filters/columns, values, statistical units, model/K/fold scope, adaptation status, p/FDR where relevant, figure identity and interpretation notes. [Paragraph mapping](../audit/claim_to_evidence_report.csv) connects the three Results sections to those records.

The ledger contains scalar findings, all final stable-pair selection frequencies, significant global term evidence and primary CellAge model evidence. It is not a claim that every individual-level source row is public. Published aggregate tables retain original numeric strings and original correction families; no FDR is recomputed after selecting significant rows for a historical display table.

Rows labeled not independently verified for donor identity deliberately preserve the distinction between samples and unique individuals. A verified numerical result can still have exploratory interpretation; verification is not causal or clinical validation.
